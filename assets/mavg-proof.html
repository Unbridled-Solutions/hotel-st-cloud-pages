The Formula

For each day of the week, the planner looks at the 4 most recent weeks with actual revenue entered for that day. It averages them: (Wk A + Wk B + Wk C + Wk D) ÷ 4. Each day is independent — Monday averages only Mondays, Saturday only Saturdays. Restaurant revenue only — event revenue is excluded from all calculations.
