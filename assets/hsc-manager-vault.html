Whistle automations

New automated message (no duplicates)

  1. Whistle → Automations → New Automated Message
  2. Internal title (guests don’t see it) · recipient type · one-time or recurring schedule
  3. Turn on Enable Multi-Reservation Messaging
  4. Turn on Enable Missed Messages (time 0 so same-day bookings still get it)
  5. Turn on Send a Message per Room, then Send Message Based on Room Status and Arrival/Departure Dates
  6. Add automation → type → channel → write the message
  7. Save bottom-right, then scroll up and save top-right. Leave without the top save and the whole automation deletes.
  8. Check Upcoming Messages for the send date so you can edit or kill it.
