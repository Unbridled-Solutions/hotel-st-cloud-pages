What changed in Quote Builder

making freedom

Forward this page. One URL. The live tool is still password FM080126. Look for v0909f in the status bar. Close old tabs.

How you use it now

Open the quote. Status is four radios: Proposed, Contracted, Completed, Lost.

To leave Proposed, tap Issue Contract. That is the only path to Contracted. You set the install date. The system fills a 90-day deposit window: 50% today, 30% in 45 days, 20% at install. You can edit the dates. Password 5476 locks it and opens the sales agreement.

Print Invoice uses the quote you have open. If that quote is contracted, the invoice names the next unpaid deposit and its due date.

Pipeline is the board for the four statuses. On a contracted job: Open quote, Open contract, Completed. Check a deposit when the money is in.
