Desk script

They booked before the change

“You are all set for 3:00.”

If the room is ready, take them. If it is not, bags in the lobby, lunch next door, text when keys are ready. Never charge them for the hour they were promised.

They booked after the change

“Check-in is 4:00.”

Early from 12:00 PM is $30 when it is available. Complimentary only if the room is already clean and it is not a same-day turn.

On a big Saturday, late checkout is for stayovers or vacant rooms, never the 2:00 PM arrival’s room. That is already “when available.” Make it the standing instruction so the desk is not negotiating it in the moment.

Folio / reservation notes

When you say go, and the key has write: one job, one sentence, only the grandfathered stays (created before the flip, arriving Oct 1 or later, still confirmed). Recut the list that morning so September bookings are included.

Standing note, posted once, before the stay:

Booked under 3:00 PM check-in. Honor 3:00 PM. No $30.

When they reply to the 1-week text with a time, add (do not replace):

ETA [time]. 3:00 PM honored. No $30.

If they never reply, the first note is enough. Silence is not a no.

Until the API write is on: desk can paste the standing note by hand on October arrivals in the first couple of weeks if that feels safer than waiting. Do not try to hand-note all 200 through May. That is the mess we are avoiding. Whistle plus the desk rule covers the long tail.
