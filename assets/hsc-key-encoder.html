1. Is Ambiance alive?

Open this on a desk computer at the hotel

http://10.100.10.6/login

That page only works on Hotel St. Cloud Wi‑Fi / wired. It will not load from your phone off property.

What “good” looks likeThe login page loads with the Hotel St. Cloud background. That means the Ambiance server is live.
What “bad” looks likeBrowser cannot reach the page, spins forever, or shows a generic error with no St. Cloud picture. That is the server / Ambiance connection. Skip the Windows restarts and go to Call support.

2. Fix it before you call

Only do this if the login page does load. If it does not load, the PC restart will not bring the server back. Call Dormakaba.

1
Restart the desk computer Start menu → Power → Restart. Not Sleep. Wait until Windows is fully back, then try a key.
2
Cloudbeds Integrator must be running Click Start. Type Cloudbeds Integrator. Open it. You want it Running, with the Ambiance connection showing.
3
Restart the Ambiance Client service Start menu. Type Services. Open Services. Find Ambiance Client. Right‑click → Restart.

Try a key now

Encode one test key for a vacant or your own test room. If it works, you are done. If it still fails, call support with the account number ready.

4. Make a key in Ambiance by hand

When to do this

  • Cloudbeds encoding fails (Error 500 / encoder not talking).
  • Family suite or PDQ keys. Those are made in Ambiance, not Cloudbeds.
  • A manager tells you to encode from Ambiance.

Most normal guest keys still encode from Cloudbeds at check-in. This is the backup path.

1
Confirm Ambiance is up Login page at 10.100.10.6 shows the St. Cloud background. Integrator running.
2
Open Ambiance on the desk PC Use the Ambiance app / desktop shortcut. Do not try this from a phone.
3
Guest Registration Front desk path: Ambiance → Guest Registration. Find the guest and the room.
4
Encode the key Put a blank or reusable card in the encoder. Encode for that room. Wait for the success message / encoder light. Pull the card.
5
Family suite / PDQ Those keys are Ambiance only. Do not expect Cloudbeds to cut them. Same Guest Registration path, that room type.

If encode fails

Do not keep swiping random cards. Go back to Fix it first. If the login page is dead, Call support. Get a manager before you hand a guest a key you have not tested on a lock.
